# Asset Provenance

## Bundled in v0.96.4

The PNG assets under `src/warpath_ce/assets/` were generated by OpenAI ChatGPT specifically for Slopfest in response to the project owner's direction. They are documented by `assets/manifest.json` and previewed in `ASSET_ATLAS_PREVIEW.png`.

No third-party graphics are bundled in v0.96.4.

## License of current bundled original assets

Unless an individual file says otherwise, current bundled original project assets are covered by the repository's root MIT `LICENSE`, as repeated in `src/warpath_ce/assets/LICENSE.txt`.

## Required import record

For every future third-party asset, record:

- repository path(s)
- creator / copyright holder
- exact source URL
- source archive/version, if available
- license and license URL/text location
- retrieval date
- modifications made
- required attribution wording

A third-party asset never becomes MIT-licensed merely because it is copied into this repository.
