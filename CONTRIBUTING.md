# Contributing to Slopfest

Thanks for helping make the galaxy stranger.

## Ground rules

1. Keep runtime pygame-family usage on **pygame-ce**, not upstream `pygame`.
2. Do not add third-party code or assets without recording provenance and license obligations.
3. For assets, update `ASSET_SOURCES.md` with exact source/file/license information before merge.
4. For dependencies, update `THIRD_PARTY_NOTICES.md` when redistribution obligations change.
5. Do not add original Warpath source code, art, sound, text, or extracted resources.
6. Keep seeded generation deterministic unless a migration is deliberate and documented.
7. Run the compile/static checks and relevant QA items before opening a pull request.

## Licensing contributions

By contributing material you have the right to contribute, you agree that your contribution may be distributed under the repository's MIT `LICENSE`, unless an accepted contribution explicitly carries another compatible license recorded in the repository.

If a contribution contains work by somebody else, say so clearly and provide its exact provenance and license.
